# /standup — the greeting ritual

1. Read docs/operational/calendar.md: the agenda and the latest Thread block.
2. Say in five lines or fewer where we were and what is open.
3. List today's and tomorrow's deadlines.
4. For every overdue task owned by the human, ask "done?" — one line each.
5. Compare `last_verified` in docs/ROADMAP.md with the latest entries of docs/operational/implementation-book.md and git log. If they diverge, say so in one line.
6. Propose the single next action. Wait.
