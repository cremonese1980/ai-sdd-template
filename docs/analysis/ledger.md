# ANALYSIS LEDGER — pre-registered analyses

Owning file for pre-registered analyses: numbered entries, numbers never reused, each with the question, the criteria and thresholds written and dated before any data is read, then the result and the decision taken. An entry is opened before the data is touched and closed when the decision is ratified; the question and criteria are never edited once the data has been read.
