# BRAINSTORM LOG — product decisions

Ledger of brainstorm closures and owning file for product decisions (architectural decisions live in adr/): one entry per closed brainstorm with date, who took part, what was decided and why, what was discarded, and what remains open. An entry is written when a brainstorm closes, never before. Language: English unless docs/PROJECT-MANIFESTO.md §8 names this file as an exception; never mixed within the file.
