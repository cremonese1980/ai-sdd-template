# RUNBOOKS

One file in this folder per known failure mode (Engineering Manifesto 6.4), each with four parts: symptom, first action, blast radius, rollback. The runbook files are PROJECT-owned. A runbook is written when a failure mode becomes known, at design time or after an incident, and updated after every incident that used it; each new file is added to docs/INDEX.md in the same turn.
