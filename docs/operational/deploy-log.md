# DEPLOY LOG

Owning file for deploys. Append-only, newest on top: one row per deploy, written by /deploy-log from the Deployer's report, with date, artefact name, version, git commit, who, result, rollback point and a link to the report. Rows are never edited or deleted; a correction is a new row.
