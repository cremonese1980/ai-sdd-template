# QUERY CATALOGUE — control queries

Numbered control queries (Q001, Q002, …), each with what it checks, the query text and the expected result. Queries are cited by code in chat, specs, handoffs and reports, never pasted into chat; a code is never reused. A query is added when a check becomes recurring, and updated in the same change as any migration that alters what it reads.
