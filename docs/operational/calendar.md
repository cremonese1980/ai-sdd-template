# CALENDAR — agenda and thread

Owning file for schedule and deadlines. Read at every greeting (/standup) and whenever a date, a deadline or "today/tomorrow" is mentioned. The agenda is updated whenever a dated task is agreed or changes status; the Thread is written by the Architect at the end of every session.

## Agenda

Rows are never deleted; status changes. Dates are ISO (YYYY-MM-DD).

|---|---|---|---|

## Thread

One block per session, latest on top: where we are, what was decided, what is open. The Architect writes it at the end of every session.
