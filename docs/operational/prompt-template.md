# IMPLEMENTER PROMPT — seven fixed points

Instantiated prompts live in tmp/ (gitignored). This format is versioned.

1. **What to read** — the sealed spec, the files it touches, the rules that apply.
2. **Branch** — name, and the worktree to use.
3. **Deliverable** — exactly what must exist at the end.
4. **Out of scope** — what must not be touched, even if it looks wrong. Findings go to TODO.
5. **VERIFY** — the checks to close in the report, each with its command.
6. **Constraints** — architecture, flags, numbers, data, time.
7. **Report format** — done; not done with reason; deviations to ratify; test counts; proposed one-line commit message (ASCII, no quotes, parentheses or metacharacters).
