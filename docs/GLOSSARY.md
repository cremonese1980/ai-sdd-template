# GLOSSARY — ubiquitous language

Owning file for domain terms (ENGINEERING-MANIFESTO 3.12): one row per term, with its meaning and where it is used. Entities, states, events, tool names and tables that carry a domain concept use these names; technical names are free. A term is added when the parliament that introduces it closes, and its row is updated when the meaning changes. Living document: `last_verified` changes only after a check against the domain package and the migrations.
